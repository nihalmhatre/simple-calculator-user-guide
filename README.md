# Simple Calculator - User Guide

## 1. Introduction

The Simple Calculator is a simple application used to perform basic mathematical calculations such as addition, subtraction, multiplication, and division.

## 2. Features

The calculator provides the following features:

* Addition
* Subtraction
* Multiplication
* Division
* Easy-to-use interface
* Fast calculations

## 3. Requirements

Before using the application, make sure you have:

* A computer or laptop
* Python installed
* A code editor such as VS Code

## 4. How to Run the Application

Follow these steps to run the calculator:

1. Open the project folder.
2. Open the terminal.
3. Run the following command:

```bash
python calculator.py
```

4. The calculator application will start.
5. Enter the required numbers and select an operation.

## 5. Available Operations

| Operation      | Symbol | Example     |
| -------------- | ------ | ----------- |
| Addition       | +      | 10 + 5 = 15 |
| Subtraction    | -      | 10 - 5 = 5  |
| Multiplication | *      | 10 * 5 = 50 |
| Division       | /      | 10 / 5 = 2  |

## 6. Example

For example, to add two numbers:

```text
Enter first number: 10
Enter second number: 5
Enter operation: +

Result: 15
```

| Problem                    | Solution                          |
